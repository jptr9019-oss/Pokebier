Como executar o projeto:

1 - REQUISITOS:

XAMPP instalado.
Apache e MySQL.
PHP com suporte a PDO e PDO MySQL.
Navegador de internet.

2 - INSTALAÇÃO:

Baixe ou clone este repositório.

Coloque a pasta Pokebier dentro da pasta htdocs do XAMPP.

Inicie os serviços Apache e MySQL pelo painel do XAMPP.

Acesse o endereço abaixo pelo navegador:
http://localhost/Pokebier/views/inicio_pokebier.php

3 - BANCO DE DADOS:

A instalação inicial do banco de dados é realizada automaticamente pelo sistema ao acessar a página inicial, caso o banco ainda não esteja instalado.

O sistema utiliza o banco de dados db_pokebier.
